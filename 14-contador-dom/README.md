# Exercício 14 — Manipulação do DOM: contador interativo

## Objetivo

Construir um contador utilizando HTML, CSS e JavaScript.

## Requisitos

A interface deve possuir:

- um número;
- botão `Incrementar`;
- botão `Decrementar`;
- botão `Resetar`.

O contador deverá possuir um limite mínimo e máximo definido no JavaScript.

## Conteúdos

DOM, `querySelector`, eventos, `addEventListener`, alteração de conteúdo e programação imperativa.

## Tarefa

Complete o arquivo `js/app.js` nos pontos marcados com `TODO`.
