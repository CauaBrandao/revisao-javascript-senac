# Exercício 15 — Mini Projeto: Todo List em JavaScript puro

## Objetivo

Desenvolver uma lista de tarefas utilizando HTML, CSS e JavaScript.

## Funcionalidades

O usuário deve conseguir:

- adicionar uma tarefa;
- visualizar todas as tarefas;
- marcar uma tarefa como concluída;
- remover uma tarefa;
- visualizar a quantidade de tarefas pendentes.

## Regra principal

Os dados devem existir em um **array de objetos**.

Sempre que esse array mudar, a interface deve ser reconstruída a partir dos dados.

Evite criar manualmente um elemento diferente para cada tarefa.

## Conteúdos

Arrays, objetos, funções, eventos, DOM, `map()`/loops, `filter()`, condicionais e separação entre dados e interface.
