# Lista de Exercícios — Revisão de JavaScript para React

Este diretório contém **25 atividades progressivas** de revisão de JavaScript.

O objetivo é preparar o aluno para React por meio de uma sequência que percorre:

- variáveis e tipos;
- operadores e condicionais;
- funções;
- objetos e arrays;
- `map()`, `filter()`, `reduce()`, `find()`, `some()` e `every()`;
- destructuring e spread;
- imutabilidade;
- DOM e eventos;
- ES Modules;
- Promises e `async/await`;
- `fetch()`;
- `localStorage`;
- organização de aplicações.

## Estrutura
Cada exercício possui seu próprio diretório e um `README.md` com o enunciado.

Nos arquivos JavaScript, os pontos que devem ser desenvolvidos estão identificados com comentários `TODO`.

## Regra geral

Os arquivos são **materiais iniciais**, não soluções prontas.

O aluno deverá completar as implementações, testar o código e refatorar quando necessário.

## Ordem recomendada

Siga os exercícios de `01` até `25`.

Os exercícios finais aproximam a lógica de JavaScript puro do modelo mental utilizado em React:

```text
dados
  ↓
transformações
  ↓
estado da aplicação
  ↓
interface
```
