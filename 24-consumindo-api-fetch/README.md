# Exercício 24 — Consumindo uma API com fetch()

## Objetivo

Realizar uma requisição HTTP, transformar a resposta em JSON e apresentar os dados na interface.

## Funcionalidades

Ao carregar a página:

1. mostrar o estado `Carregando...`;
2. executar `fetch()`;
3. converter a resposta com `.json()`;
4. armazenar os dados recebidos;
5. renderizar os itens;
6. tratar possíveis erros.

## API

O arquivo `js/app.js` possui uma constante `API_URL`.

O professor pode indicar uma API pública específica. Caso nenhuma seja fornecida, utilize uma API pública de testes adequada à atividade.

## Conteúdos

`fetch()`, HTTP, Promises, `async/await`, JSON, `try/catch`, DOM e renderização de dados.
